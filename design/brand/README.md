# OotleAccord identity — direction 01

The selected direction is the interlocking OA monogram. Its lower curve connects the O to the A crossbar, suggesting an agreement between participants.

Production assets:

- `app/brand/mark-v2.svg`: transparent single-color symbol.
- `app/brand/app-icon-v2.svg`: symbol on a dark rounded tile, used in the app header and favicon.
- `app/brand/wordmark-v2.svg`: horizontal symbol and wordmark for dark backgrounds. Its text uses a local system-font stack.

Colors: pale lime `#c9eea7`, forest `#153d38`, dark app background `#101713`, off-white wordmark `#edf4e8`. Keep the narrow cuts and both counters clear at small sizes. SVG files contain their own geometry and make no external requests.

The built-in image generation tool was used for concept exploration and the selected-mark refinement. Production assets use clean, hand-authored SVG geometry instead of the raster preview.
